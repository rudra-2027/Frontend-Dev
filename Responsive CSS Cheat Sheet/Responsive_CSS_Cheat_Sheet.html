Responsive CSS Cheat Sheet

Media Queries

Used to apply styles based on screen size or device type.
@media (max-width: 600px) { ... }

Responsive Design

Ensures your layout adapts smoothly to different devices and resolutions using flexible units, grids, and media queries.

Filters

Apply visual effects to images or elements.
filter: grayscale(100%); or filter: blur(5px);

Typography

Use relative units and the clamp() function to make text scale responsively.
font-size: clamp(1rem, 2vw, 2rem);
